📊 Stokastic Projection Methodology

Following the Stokastic framework: estimate opportunity first, multiply by efficiency, adjust for matchup, anchor to Vegas, then convert to projected points.

1. Opportunity (Volume)

Target share, snap share, rush attempts from nflverse weekly stats

2. Efficiency

Yards per route run, yards per carry, EPA per play

3. Matchup

Opponent defense strength, position-specific leaks

4. Vegas Anchor

Implied team total from spread & game total

5. Game Script

Trailing teams pass more, leading teams run more

6. Value Calc

Model vs Line: +edge if model > line (over) or model < line (under)
